## 🌾 What DiLi is aiming at

- 🌾 **AgriTech** — decision support for smallholder farmers, where the margin for error is thin
- 🏠 **Smart home & automation** — practical, offline-tolerant, affordable
- 🗣️ **AI for indigenous languages** — Hausa, Yoruba, Igbo and beyond; multilingual NLP as access, not novelty
